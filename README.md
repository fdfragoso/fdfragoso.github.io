## Publicar no GitHub Pages
1. Criar um repositório portfolio na sua conta GitHub (público, para a opção mais simples).
2. Enviar index.html, styles.css e .nojekyll para a raiz da branch main. README.md é opcional.
3. Em Settings → Pages → Build and deployment, escolher Deploy from a branch.
4. Escolher main e /(root), e salvar.
5. Acompanhar o deployment em Actions/Pages e usar o endereço exibido pelo GitHub.
6. Abrir o endereço no celular e no computador antes de compartilhar.

Projeto de repositório: https://SEU_USUARIO.github.io/portfolio/
Para endereço na raiz: repositório SEU_USUARIO.github.io.
